SECTION 01  ·  WINDOWS  ·  10월호 후속
Windows Hybrid Intelligence, FinOps로 다시 보기
Local + Cloud AI = AI 크레딧을 아끼는 구조
지난 호 요약 10월 7일 발표된 Windows Hybrid Intelligence — 에이전트가 적합할 때는 PC(로컬)에서, 필요할 때는 클라우드에서 일하는 플랫폼
Copilot+ PC의 로컬 컨텍스트 · 로컬 작업 · 로컬 모델  |  에이전트 격리를 위한 Microsoft Execution Containers(MXC) 정식 출시
왜 FinOps인가 AI 수요가 클라우드 예산이 감당할 수 있는 속도보다 빠르게 늘고 있습니다. 로컬 AI와 클라우드 AI를 결합하면 필요한 역량은 유지하면서 토큰 · 예산을 효율적으로 쓸 수 있습니다.
GitHub HydraFusion: 작업별로 로컬 · 클라우드 모델을 라우팅 (10월 말 실험적 프리뷰 예정으로 발표)
크레딧 경제학 모든 작업이 같은 비용일 필요는 없습니다.
일상 업무사용자 라이선스(USL)
Cowork · Code · Autopilot
프론티어 모델		사용량 기반 과금(UBB) — 크레딧 소진
PC에서 처리 가능한 작업Copilot+ PC의 로컬 모델로 분담 → 클라우드 크레딧은 고난도 작업에 집중
관리 도구 FinOps for AI — 지출 정책, 크레딧 요청 승인, 사용자 그룹별 사용 가능 모델군 설정, 크레딧 사용량 · 잔액 · 이력 가시화
로컬 실행 에이전트도 MXC로 파일 · 네트워크 접근 범위를 정책으로 제한 — Agent 365 · Intune 연동
CxO 시사점 AI 비용은 ‘얼마나 쓰느냐’만이 아니라 ‘어디서 처리하느냐’로 결정됩니다. PC 교체 계획과 AI 크레딧 예산을 하나의 계획으로 보셔야, 같은 예산으로 더 많은 업무를 AI에 맡길 수 있습니다.

“이 슬라이드의 핵심 메시지 3가지를 임원 보고용 한 장 비주얼로 정리해 줘. 항목마다 아이콘을 넣고, 숫자는 크게 강조하고, 회사 브랜드 색상을 유지해 줘.”
CxO 시사점 보고 자료의 완성도가 ‘디자인을 잘하는 한 사람’에 의존하지 않게 됩니다. 우리 회사의 보고 형식 · 검토 기준을 Skill로 만들어 두면 전사 보고 품질이 표준화됩니다.

SECTION 03  ·  POWERPOINT SKILLS  ·  FRONTIER
Interactive Slide — 대화형 슬라이드
발표자와 청중이 함께 클릭하며 탐색하는 장표
무엇이 Copilot이 만든 클릭해 탐색하는 슬라이드 — 대시보드 · 타임라인 · 요약을 발표자와 청중이 함께 눌러 보며 맥락 · 단계 · 데이터를 펼쳐 봅니다.
9월호에서 소개한 ‘선형 → 반응형 프레젠테이션’이 실제 업무 도구로 들어왔습니다
사용법 PowerPoint 홈 또는 삽입 리본의 ‘Interactive Slide’ 선택 → Copilot에 원하는 장표를 설명
Copilot 스킬 선택기의 Create interactive slide로도 시작 가능
